Base de motoristas: o sistema considera os 3 cargos definidos e mostra a soma de todos eles. Exemplo: 238 ônibus + 69 micro-ônibus + 73 vans = 380 motoristas.

Como funciona: importe a planilha de funcionários uma vez e depois importe os logs de cada dia. O sistema considera somente MOTORISTA - ÔNIBUS, MOTORISTA - MICRO ÔNIBUS e MOTORISTA - VAN. Um motorista é considerado usuário no dia quando seu nome aparece pelo menos uma vez nos logs.
Conferência da base Importe a planilha de funcionários para validar a quantidade por cargo.
